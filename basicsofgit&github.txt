Branching Concept:
main branch has important codes
sub branches are created for working individually assigned work and then committing then to the main branch.

viewing your current branch - git branch 
creating new branch-    git branch branchname
lisiting all the branches - git branch -a
create a new branch in the web GitHub
now give the command - git pull 
check again, list all the branches 
move or open to your new created branch -
#git checkout branchname
git checkout gitbranch1
create a file and then add commit and push.
changes will be seen in secondary branch but not in main branch, we will have to move the changes to the main branch for that we use -
git diff gitbranch1 
(to see the differences)
merging main and create sub branche
#git merge branchname
git merge gitbranch1 
push now 
git push origin main
clear - clearing all commands
